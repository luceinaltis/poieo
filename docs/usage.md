# Using poieo

Pick the guide for what you want to do. Each opens as a separate page on
[the documentation site](https://luceinaltis.github.io/poieo/docs.html).

| Guide | What it covers |
|---|---|
| [Get started](guides/getting-started.md) | Install and open your first board |
| [Models](guides/models.md) | Connect models and assign small and large ones to steps |
| [Tasks](guides/tasks.md) | Create, schedule, and direct work |
| [Changes](guides/changes.md) | Review, apply, and undo work |
| [Troubleshooting](guides/troubleshooting.md) | Find why a task, model, or change failed |

For technical details, use the [component reference](README.md#change-poieo).
