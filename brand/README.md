# The brand

poieo's identity is **a tree in a harness**: something alive and a little
wilful — branches that grow where they decide to, each twig carrying a round
bud — held and kept by a frame that lets it work. The tree is the work growing
overnight; the one amber bud is the task running right now; the harness is
poieo.

The look started from a kinetic sculpture (a sphere sprouting crooked
ball-tipped stalks) and was pushed toward modern-art tree forms. Three
generated references set the register — keep their qualities, not their exact
pixels:

| file | what it holds |
|---|---|
| `mark-source.jpg` | THE mark's source — the simplified two-branch tree the site's SVGs are traced from |
| `reference-crooked-tree.jpg` | the rich register: the full wilful crooked tree (hero and social-card art) |
| `reference-windswept-tree.png` | the dramatic register — motion, one fruit about to let go (also the inverted light-ground accident worth keeping) |
| `reference-ikebana-branch.png` | the minimal register — one pruned branch, editorial air; the small-size direction |

Colours are the board's own (`web-ui/src`): ground `#14120f`, parchment
`#e8e2d8`, ember `#d8a657` (exactly one amber element per mark), live
`#a9b665`. Type: the traced custom wordmark (`site/img/wordmark.svg`);
sentences in Hanken Grotesk, labels and figures in DM Mono.

Rules of thumb: crooked stays crooked — do not tidy the branches straight;
one amber bud, never more; flat vector, no gradients; on light grounds swap
parchment for ink `#221e18` and keep the amber.
