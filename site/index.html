Get started in sixty seconds

Set a folder up

mkdir ~/board && cd ~/board
poieo init

It finds every model server on this machine and writes the result to plain files. No model yet? --mock gives you a stand-in that spends nothing.

Write a card

# ~/board/tasks/keep-green.yaml
name: keep the tests green
folder: ~/code/thing
prompt: |
  Run the tests. If one fails,
  find out why and fix it.

That is the whole file — everything else has a default.

Leave it running

poieo daemon

Every card in tasks/ now runs on its schedule, and the board is at 127.0.0.1:8484. A task is a file: drop one in, delete it out.

The night, and the morning after

Tasks work in a private copy, never in your checkout. Each run leaves at most one change.

In the morning, read the diff and accept it — the only moment poieo writes to your branch — or discard it; nothing is lost for good.

Why it earns a place on your machine

Cheaper than doing it one prompt at a time
Each step names a role, and you pick the model that serves it — free ones for the night shift, a costly one only where it pays.
The whole flow on one board
One graph shows every task and its wiring; any run replays what it did, turn by turn.
One memory, shared by every task
A lesson one task learns lands in shared memory, and every task reads it before working.
Tasks that learn their job
Journals plus a learning pass mean next week starts where this week ended — never from zero.

One person's machine, running one person's work

No accounts, no server, no team features — and no plan to have them. Everything on this page ships today.
