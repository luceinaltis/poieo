The right intelligence, in the right place.

Small and large models, working together.

Give routine work to a small model and demanding steps to a larger one. poieo keeps your tasks running, carries their context forward, and records the results.

Runs on your machine. Works with local and cloud models.

Spend the intelligence
where it earns its place.

The goal is more accuracy for the cost. Start with a small model, use a larger one where the task needs it, and judge the result against your checks.

Keep the everyday light.

Reading, sorting, routine checks. Give frequent, well-bounded steps a model that handles them economically.

Give hard work more room.

Bring a larger model into the steps that need deeper reasoning or more context. Change the model without rewriting the work.

Let the result prove itself.

Build tests and review into your task. Inspect what ran, what changed, and the usage and cost the model reports.

You choose the model for each step. Savings and accuracy depend on your models, tasks, and checks.

Set the work in motion.
Come back to something clear.

Write the task once. It keeps its schedule and its journal, so each run starts with context from the last.

task

Write the task

A name, a folder, and what you want done. Begin with one model; add more steps when the work needs them.

run

Let it run

poieo runs the task on your schedule and records what happened. Pause it, try it again, or follow its progress.

change

Review the change

In a Git project, work happens in a private copy. Read the diff, then accept it or set it aside.

The next run has a starting point.

Each task keeps a journal. Project memory can share learned context across tasks. Your work stays in files and records you can inspect.

Install and create a project

git clone https://github.com/luceinaltis/poieo
cd poieo
pip install .

mkdir my-board
cd my-board
poieo init --mock

Save a task in tasks/keep-green.yaml

name: keep the tests green
folder: /path/to/your/git-project
prompt: |
  Run the tests. Find and fix a failing test.
  Run them again to check the change.

Choose an existing folder. The mock exercises the loop without calling a real model.

Keep it running

poieo daemon

Open the board at http://127.0.0.1:8484. Then choose the models for your real work.

A personal tool for work that keeps going.
